## Start in 60 seconds

Start the server with Docker:

```sh
docker run --rm -p 9000:9000 ghcr.io/schmas/fauxidc
```

Or download the binary from the [GitHub releases](https://github.com/schmas/fauxidc/releases),
or install it with `cargo install fauxidc --locked`.

With no config, fauxidc starts in Zero config mode: one Issuer `default` in Lenient mode,
one public Client `test`, and the Users `alice` and `bob`. In a second terminal:

```sh
# Discovery document
curl -s http://localhost:9000/default/.well-known/openid-configuration
# Tokens for alice, without a browser
curl -s http://localhost:9000/_mock/default/token -H 'content-type: application/json' -d '{"user": "alice"}'
# Health check
curl -s http://localhost:9000/_mock/health
```

Point your app at the Issuer URL `http://localhost:9000/default` with the client id `test`.
Open `http://localhost:9000/default/debugger` and click "Run login flow" to see the login page.

The [README](https://github.com/schmas/fauxidc#start-in-60-seconds) has all the install options.

## Use with an AI coding agent

A coding agent can add fauxidc to an app project, write its config, mint tokens in tests and inject failures.
The repo gives the agent two skills: [skills/fauxidc](https://github.com/schmas/fauxidc/blob/main/skills/fauxidc/SKILL.md) (reference)
and [skills/fauxidc-setup](https://github.com/schmas/fauxidc/blob/main/skills/fauxidc-setup/SKILL.md) (project setup).
[llms.txt](https://github.com/schmas/fauxidc/blob/main/llms.txt) lists the docs for agents that read it.
Install the skills, then give your agent a prompt such as:

```text
Our single-page app uses oidc-client-ts. Make it log in against a local fauxidc in Zero config:
start it with "docker run --rm -p 9000:9000 ghcr.io/schmas/fauxidc".
Use the authority http://localhost:9000/default, the public Client id "test", the code flow with PKCE (S256)
and the scope "openid profile email". Put these values in .env.development, not in the code.
Then open the app, log in as alice on the fauxidc login page and check that the app shows her email.
```

```text
Write an integration test for GET /api/orders of our API. Start fauxidc with examples/generic.toml
(Issuer "generic" at http://localhost:9000/generic). Before the request, mint an access token with the Test API:
POST http://localhost:9000/_mock/generic/token with the JSON body
{"user": "alice", "audience": "https://api.example.test", "claims": {"roles": ["viewer"]}}.
Send the access_token as a Bearer token and expect 200. Add a second test that mints a token with
"expires_in": -60 and expects 401. Configure the API to trust the issuer http://localhost:9000/generic
and to accept the access token header typ "at+jwt".
```

For more prompts and the install steps, see <DocLink doc="agents.md" fallback={`${GH}/blob/main/docs/agents.md`}>Use fauxidc with an AI coding agent</DocLink>.
