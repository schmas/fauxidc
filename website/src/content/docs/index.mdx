## Start in 60 seconds

Start the server with Docker:

```sh
docker run --rm -p 9000:9000 ghcr.io/schmas/fauxidc
```

Or download the binary from the [GitHub releases](https://github.com/schmas/fauxidc/releases),
or install it with `cargo install fauxidc --locked`.

With no config, fauxidc starts in Zero config mode: one Issuer `default` in Lenient mode,
one public Client `test`, and the Users `alice` and `bob`. In a second terminal:

```sh
# Discovery document
curl -s http://localhost:9000/default/.well-known/openid-configuration
# Tokens for alice, without a browser
curl -s http://localhost:9000/_mock/default/token -H 'content-type: application/json' -d '{"user": "alice"}'
# Health check
curl -s http://localhost:9000/_mock/health
```

Point your app at the Issuer URL `http://localhost:9000/default` with the client id `test`.
Open `http://localhost:9000/default/debugger` and click "Run login flow" to see the login page.

The [README](https://github.com/schmas/fauxidc#start-in-60-seconds) has all the install options.

## Use with an AI coding agent

The repo has an agent skill, [skills/fauxidc](https://github.com/schmas/fauxidc/blob/main/skills/fauxidc/SKILL.md).
It tells a coding agent how to start fauxidc, write a config, mint tokens and inject failures.
[llms.txt](https://github.com/schmas/fauxidc/blob/main/llms.txt) lists the docs for agents that read it.
Install the skill, then give your agent a prompt such as:

```text
Add fauxidc to this project as the local OpenID Connect provider.
Write a config with a public Client for the SPA at http://localhost:5173/ and the Users alice and bob.
```

```text
Write an integration test for the API. Mint a token for alice with the role "viewer" from the fauxidc Test API.
Check that the API rejects an expired token.
```

For more prompts and the setup, see <DocLink doc="agents.md" fallback={`${GH}#use-with-an-agent`}>Use fauxidc with an AI coding agent</DocLink>.
